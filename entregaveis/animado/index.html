Carrossel animado

Oito slides em vídeo, feitos sem abrir editor. O Claude escreve a animação, o Remotion renderiza o arquivo. Aqui estão os três passos, o componente mínimo que já funciona, o comando de render e as duas armadilhas que fizeram o meu primeiro render falhar em silêncio.

O slide 1 do carrossel. O texto fica parado; o que se mexe são as miniaturas, que trocam de conteúdo.

O motivo

Vídeo que se reescreve sem refazer

Num editor de linha do tempo, mudar uma palavra da manchete significa reposicionar tudo que estava encaixado nela. Aqui a animação é código: a manchete é uma variável, o movimento é uma função do tempo, e trocar o texto de oito slides é editar oito linhas e rodar o render de novo. É a mesma diferença entre reescrever um documento e reimprimi-lo.

O custo disso fica em zero. Nenhum slide é gerado por IA de vídeo: o fundo e o texto são fixos, e o único elemento que se move é animado na própria composição, que é uma página animada gravada em vídeo. Até o slide que mostra um card ganhando vida é código: a capa é recriada dentro do Remotion e se monta peça por peça na tela.

A regra que sustenta tudo

Um elemento se move por slide

01

O movimento aponta para a lição

Se o slide ensina que o primeiro slide vira o sistema, o que se mexe são as variações aparecendo. O texto fica parado. Duas coisas se mexendo ao mesmo tempo viram ruído e o olho não sabe onde pousar.

02

Quatro segundos por slide

É o tempo de ler a manchete e ver o movimento acontecer uma vez. Mais que isso, a pessoa arrasta antes do fim e você animou para ninguém.

03

A pílula do CTA aparece em todos os slides

Não só no último. Quem sai no slide 4 precisa saber qual palavra comentar. É a diferença entre um carrossel bonito e um carrossel que gera conversa.

E uma quarta, que só aparece depois de errar: as demonstrações dentro dos slides são peças reais suas, não ilustração genérica. O carrossel animado que mostra carrosséis mostra os seus. É o que separa demonstração de propaganda.

Passo 1

Comece pelo contexto

Antes de desenhar qualquer coisa, peça o roteiro. Slide a slide, com o que se mexe em cada um já definido. Decidir a animação depois do desenho é o caminho mais rápido para oito slides bonitos que não contam nada.

  1. Abra o Claude Code na pasta do projeto

    Com as suas skills de design já instaladas, se você tiver.

  2. Cole a pauta e quem é o público

    Sem isso ele escreve para ninguém.

  3. Peça o roteiro slide a slide

    Um passo por slide, e o que se mexe em cada um.

  4. Revise a ordem antes de desenhar

    Trocar a ordem no texto custa um minuto. Depois de renderizado custa a tarde.

o pedido do roteiro
monte o roteiro de um carrossel de 8 slides sobre [o seu tema]. um passo por slide, com o que se mexe em cada um. o público é [quem]. a última linha de cada slide tem que caber em uma manchete curta e em caixa alta.
Passo 2

O primeiro slide vira o sistema

Não peça os oito de uma vez. Peça várias versões só do primeiro slide, escolha uma, e diga que essa é o padrão. Os outros sete nascem dela: mesma grade, mesma tipografia, mesma cor de acento, mesmo rodapé. O trabalho de design acontece uma vez.

Mostre o estilo, não descreva. Mandar o print de um carrossel que você gosta e dizer "use isto como referência de design" funciona melhor do que qualquer adjetivo. Guarde numa pasta as referências que já deram certo: elas viram o seu repertório e param de depender da sua memória.

Passo 3

Anime com Remotion

O Remotion é o que transforma uma página animada em arquivo de vídeo. Ele é grátis para pessoa física e para empresa de até três funcionários; acima disso a empresa compra a licença.

1080 × 135030 fps120 frames · 4 sum slide por render
criar o projeto
npx create-video@latest

O projeto já nasce com um src/Root.tsx e uma composição de exemplo. Troque a composição pela sua e escreva o slide como um componente comum. Este é o menor slide que já se move de verdade:

src/Slide.tsx
import {AbsoluteFill, useCurrentFrame, interpolate} from 'remotion';

export const Slide: React.FC<{titulo: string}> = ({titulo}) => {
  const frame = useCurrentFrame();
  const sobe    = interpolate(frame, [0, 24], [70, 0], {extrapolateRight: 'clamp'});
  const aparece = interpolate(frame, [0, 24], [0, 1],  {extrapolateRight: 'clamp'});

  return (
    <AbsoluteFill style={{backgroundColor: '#0B0A08', justifyContent: 'center', padding: 80}}>
      <div style={{
        fontFamily: 'Anton', fontSize: 130, lineHeight: 1.02, color: '#F2EDE4',
        textTransform: 'uppercase',
        transform: `translateY(${sobe}px)`, opacity: aparece,
      }}>{titulo}</div>
    </AbsoluteFill>
  );
};
src/Root.tsx
import {Composition} from 'remotion';
import {Slide} from './Slide';

export const RemotionRoot: React.FC = () => (
  <Composition
    id="Slide"
    component={Slide}
    durationInFrames={120}
    fps={30}
    width={1080}
    height={1350}
    defaultProps={{titulo: 'Pare de fazer carrossel parado.'}}
  />
);

npx remotion studio abre a prévia no navegador, com a barra de tempo. É onde você acerta o movimento antes de renderizar.

O render

Um slide por arquivo

Cada slide sai num render próprio, com um número diferente na entrada. Grave o número num arquivo JSON e passe o caminho:

render · Windows
mkdir out props
echo {"slide":1} > props/1.json

npx remotion render src/index.ts Slide out/slide-1.mp4 ^
  --props=props/1.json ^
  --browser-executable="C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe"

No Mac e no Linux troque o ^ por \ no fim das linhas, e o --browser-executable normalmente nem é necessário.

O que me custou uma noite

As duas armadilhas do Windows

01

O navegador que o Remotion baixa sozinho falha calado

Ele avisa que está baixando, o download termina, o processo sai com código de sucesso e nenhum arquivo aparece. Não há mensagem de erro para procurar no Google. A cura é apontar para o Edge ou o Chrome que já estão instalados, com --browser-executable, como no comando acima.

02

As aspas do --props não sobrevivem ao terminal

Passar o JSON direto na linha de comando parece funcionar e chega quebrado do outro lado. Grave num arquivo e passe o caminho. Sempre.

Estas duas não estão no topo de nenhuma documentação, e juntas elas produzem o mesmo sintoma: o comando termina bem e não existe vídeo nenhum. Se você bater nisso, não é você.

Antes de publicar

Confira os oito

Render que falha calado não avisa duas vezes. Antes de subir, conte os arquivos e leia as dimensões de cada um:

conferência
for i in 1 2 3 4 5 6 7 8; do
  ffprobe -v error -show_entries stream=width,height,duration -of csv=p=0 out/slide-$i.mp4 || echo "slide $i FALTOU"
done

Quando dá errado

Consertos

SintomaO que fazer
O comando termina bem e não há arquivoÉ a armadilha 01. Aponte o --browser-executable para o Edge ou o Chrome instalado.
"Timed out after 25000 ms while trying to connect to the browser"Acontece de vez em quando, com qualquer navegador, e não quer dizer que o caminho está errado. Rode o mesmo slide de novo. Num lote, faça o script tentar outra vez quem falhou.
"Visited localhost:3000 but got no response"Acontece de vez em quando com muitos renders em paralelo. Rode de novo com --concurrency=2.
A fonte aparece errada no vídeoA fonte precisa terminar de carregar antes do primeiro frame. Se você usa fonte da web, segure o render até ela carregar com delayRender e continueRender.
O texto pisca ou salta no inícioVocê animou a partir do frame 0 sem extrapolateRight: 'clamp'. Sem o clamp, o valor continua crescendo depois do fim.
Ficou pesado para o InstagramNão recomprima os masters. Renderize já no tamanho certo e mande esses arquivos.
Se só lembrar disso

Roteiro antes do desenho. Um elemento se move. O primeiro slide vira o sistema.
